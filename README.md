# MEP Design Sheets

A practical collection of engineering spreadsheets, calculation sheets, templates, and reference material for building-services design. The repository brings together resources covering HVAC, electrical systems, lifts, lighting, mechanical design, medical gases, networking, and plumbing.

## Resource index

| Discipline | Available resources |
|---|---|
| **HVAC** | Acoustic calculations, chilled-water pump selection, duct static calculations, HVAC insulation design, heat-load calculations with solar gains, stack-effect ventilation, OpenStudio templates, and sample files |
| **Electrical system design** | Earthing design, lightning-risk assessment, load estimation, short-circuit calculations, and voltage-drop calculations |
| **Lifts** | Lift traffic analysis and lift planning |
| **Lighting** | Coefficient-of-utilization (CU) tables and lumen-method calculation sheets |
| **Mechanical** | Beam-deflection calculations |
| **Medical gas** | Medical-gas line sizing reference sheet based on HTM 02-01 |
| **Networking** | Network bandwidth calculation |
| **Plumbing** | Borewell calculations, flow in partially filled pipes, and pump-related resources |

## Using the calculation sheets

1. Open the relevant discipline folder and review the file before entering project data.
2. Check units, assumptions, input ranges, and calculation methods against the requirements of the project.
3. Independently verify important results before using them for design, procurement, construction, or commissioning.
4. Confirm applicable local regulations, standards, and authority requirements. A reference to a standard in a file does not guarantee that the sheet reflects its latest edition.

## Scope and limitations

These files are shared as engineering references and working tools. They are not a substitute for project-specific engineering judgement, independent checking, statutory review, or approval by the responsible qualified professional. Users are responsible for validating formulas, assumptions, source data, and outputs before relying on them.
